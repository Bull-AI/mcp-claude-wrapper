# Security Policy

Report suspected vulnerabilities in the Bull AI remote MCP integration through
the [Bull AI contact route](https://www.bull-ai.in/contact).

Do not include access tokens, refresh tokens, authorization codes, PKCE values,
cookies, client secrets, customer data, or raw request/response captures. Include
a minimal reproduction and the public endpoint instead.

This package is only a pointer to Bull AI's remote MCP server. It must not add
credentials, a local proxy, private service URLs, deployment configuration, or
copied application code.
